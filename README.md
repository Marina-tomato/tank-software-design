# Танки

Для запуска нужна Java 17. `./gradlew run` читает карту из `src/main/resources/level.txt`. Строки идут сверху вниз. `T` обозначает дерево, `X` задаёт старт игрока, `_` оставляет клетку пустой.

- `./gradlew run --args=random` создаёт случайную карту.
- `./gradlew run --args=/полный/путь/карта.txt` загружает свою прямоугольную карту с одним игроком.
- Стрелки и WASD управляют танком. Пробел делает один выстрел. Синий танк принадлежит игроку. Остальные танки получают рекомендации о направлении и стрельбе, а при отсутствии рекомендации выбирают случайное действие.
- Клавиша L включает и выключает полоски здоровья всех танков. У каждого танка в начале 100 очков здоровья.
- `./gradlew test` запускает модульные тесты.

## Состояния танка

| Осталось от начального здоровья | Время на клетку | Стрельба |
| --- | --- | --- |
| Больше 70 % | 0,4 с | Доступна |
| От 15 до 70 % включительно | 0,8 с | Доступна |
| Меньше 15 % | 1,2 с | Заблокирована |

После попадания танк пересчитывает состояние. Если он уже движется, пройденная часть пути сохраняется. При нуле здоровья танк исчезает с поля. Интерфейс `TankState` задаёт скорость и возможность выстрела. Временное усиление можно реализовать отдельным состоянием с переходом обратно в состояние по здоровью после окончания эффекта.

## Порты и адаптеры

| Слой | Что в него входит |
| --- | --- |
| Домен | `model` хранит сущности, правила перемещения, попаданий и смены состояния. `PlayingField` реализует `Passability` и `ProjectileSink` для танков. |
| Приложение | `GameLoop` запрашивает команды через `Controller`, исполняет их, обновляет поле и вызывает выходной порт `Display`. `Move`, `Fire` и `ToggleHealthBars` реализуют действия. `EnemySpawner` расставляет противников. |
| Ввод | `DesktopKeyboard` читает клавиши LibGDX. `RandomDriver` подаёт команды ИИ и запрашивает совет через `RecommendationSource`. `AdvisorAdapter` переводит ответ `AimAdvisor` в команду. |
| Вывод | `GameView` реализует `Display` и `FieldListener`. Через первый порт приходит запрос на кадр, через второй — сведения о появлении и удалении объектов. Графические утилиты и декоратор находятся на стороне представления. |
| Загрузка | Порт `LevelSource` возвращает `Layout`. `TextLevel` разбирает текст, а `RandomLevel` создаёт карту. `GameDesktopLauncher` выбирает источник, читает файл через LibGDX и связывает компоненты. |

При добавлении сетевых карт чтение файла и сетевой запрос можно вынести за общий порт получения текста. Сейчас чтение используется только в точке запуска. Если понадобится сохранять игру, потребуется отдельный порт для снимка поля и адаптер хранилища.
